EduPathAI – AI Web Platform

EduPathAI is an AI-powered web platform that helps students discover the most suitable university major based on their interests, academic performance, and career goals.

Technologies:
PHP, MySQL, HTML, CSS,bootstrap, JavaScript, python .

Features:
User questionnaire about interests and goals,
AI-based recommendation system,
Displays suggested university majors,
Simple and user-friendly interface.

How to run:
1. Clone the repository
2. Import the database into MySQL
3. Run the project using a local server (XAMPP or WAMP)
4. Open the project in your browser
